# Adult Income Classification

## a. Problem statement

This project compares five supervised classification algorithms for predicting whether a person's annual income is greater than $50,000 using demographic and employment attributes. The positive class is `>50K`. This educational model comparison is not intended for consequential decisions about individuals.

## b. Dataset description

**Dataset:** Adult (Census Income) dataset  
**Source:** [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/2/adult)  
**Training source file:** `adult.data` from the official UCI archive  
**Rows used:** 32,561 labeled records  
**Input features:** 14  
**Target:** `income`, with classes `<=50K` and `>50K`

The features include age, work class, education, marital status, occupation, relationship, race, sex, capital gains and losses, hours worked per week, and native country. The UCI file uses `?` to mark missing values; numeric values are median-imputed and scaled, while categorical values are mode-imputed and one-hot encoded inside each saved pipeline. A stratified 80/20 split with random seed 42 is used for evaluation. The holdout test CSV is generated by the training script.

## d. Models used

The five models are Logistic Regression, Decision Tree, K-Nearest Neighbors, Gaussian Naive Bayes, and Linear Support Vector Machine. Each model uses a training-fitted preprocessing pipeline. Accuracy, ROC AUC, precision, recall, F1-score, and Matthews Correlation Coefficient (MCC) are calculated on the same stratified test split.

Run the training script to generate `results/model_comparison.csv`; use those measured values in this table and base the observations below on the actual results.

## Run locally

From this directory:

```bash
python -m pip install -r requirements.txt
python train_models.py
python -m streamlit run app.py
```

The trainer downloads the public UCI data if `data/adult.data` is not present. It saves five fitted pipelines under `model/`, the labeled holdout set as `test_data.csv`, and measured scores as `results/model_comparison.csv`. The Streamlit app evaluates the bundled test data or an uploaded labeled test CSV without retraining.
